This category owns clothing, shoes, bag/accessories and body styling references.

knee-length skirt, sheer dark tights, black heels, burgundy lanyard and a bag on
Riley's anatomical right shoulder.

- `images/`: original outfit references and new cyberpunk wardrobe concepts,
  each with its generation record.
- `prompts/`: wardrobe-specific prompts.

  tank-top outfit or tattoos for Riley.

  shared character links and the status of post-upgrade wardrobe development.

  inspiration, archived unchanged with provenance; no identity transfer.
