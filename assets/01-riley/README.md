# Riley — identity and cyberware

This category owns Riley's face, hair, expressions and facial/neck cyberware.
The existing `riley-01-v01.png` remains the canonical identity reference.
New concepts do not automatically replace it.

- `images/`: versioned portraits and their `.generation.json` records.
- `prompts/`: exact submitted character-design prompts.
- `references/cyberpunk/`: user-supplied facial styling references and provenance.
- [cyberpunk-manifest.json](cyberpunk-manifest.json): current concept states,
  source dependencies and selection; paths are relative to `assets/`.
- [CYBERPUNK-GALLERY.md](CYBERPUNK-GALLERY.md): the four inexpensive options.
